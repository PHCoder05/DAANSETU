# CompleteU

This is the new application `CompleteU`, built on top of the CompleteU Core SDK.

## Getting Started

1.  **Install Dependencies**:
    ```bash
    flutter pub get
    ```

2.  **Run the App**:
    ```bash
    flutter run
    ```

## Structure
- `lib/core`: Core utilities and services.
- `lib/shared`: Shared widgets and models.
- `lib/config`: Configuration files.
