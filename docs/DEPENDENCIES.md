# DAANSETU - Dependencies

## Node Dependencies

### OS
-   Windows (verified)
-   macOS (verified)
-   Linux (verified)

### Runtime
-   **Node.js** 18+ (LTS recommended)
-   **npm** 8+ or **yarn** 1.22+

### Node.js Version Manager (Optional)
-   nvm (Node Version Manager)
-   fnm (Fast Node Manager)

## MongoDB Dependencies

### MongoDB
-   Version 6.0+
-   Atlas (cloud) or local installation

### Recommended Tools
-   MongoDB Compass (GUI)
-   mongosh (shell)

## Flutter Dependencies

### Flutter SDK
-   Version 3.0+
-   Dart 3.0+

### IDE
-   VS Code with Flutter extension, OR
-   Android Studio with Flutter plugin

### Platform Tools
-   **Android:** Android SDK, Java 11+
-   **iOS:** Xcode 14+, CocoaPods (macOS only)
